# EndCrast

## Project Goal

Build a full stack web application including AI, and a well defined structure with easy navigation for users to get a full resource list and learn about a specific topic.

## Requirements

- Get required input from users like name and description of project, timeline, deadline, and time allocated per day for learning
- Give reality check, and make adjustments about how deep the resources should teach in that time period
- Find useful Learning resources
- Create a full schedule along with the learning material
- Create quizes and real time facts at the end of the each schedule
- Give small and large projects to evaluate progress
- progress should be presented on the frontend, along with profile
- Give reality check or how better or how much more efforts they should put
